  #  UNIVERSITY SYSTEM
  # A UNIVERSITY LAYOUT SYSTEM DATABASE SCHEMA
  ## Overview
  This database is designed to project the layout of a university system but varies with different institutions. It organizes the students, courses, departments ,lecturers and their relationship enabling easier data retrival and management.

  ## HOW TO IMPORT
  ### USING THE COMMAND LINE
  1.Open your terminal or command prompt.
  2.Log in to MySQL:
  mysql -u your_username -p
  3.Run the SQL file:
  SOURCE /path/to/your/sqlfile.sql;
 ### USING THE WORKBENCH
 1.Open MySQL Workbench.
 2.Connect to your local or remote server.
 3.Go to File > Open SQL Script, and select the .sql file.
